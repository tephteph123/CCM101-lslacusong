# Bash Script

A bash script is a script that contains commands for the Linux operating system that are designed to automate a task, such as backing up data from the client. The first line of the file, "#!/bin/bash", is a directive to Linux to use the Bash shell to run the commands in the file.

## Variables

Programmers use variables like `$BACKUP_DIR` to store a folder path in one place. It makes it easier to read and update scripts because they don't have to modify a large number of folder paths in the script.

## Cron Job

A cron job is a task or script that is executed at a specified time or after a specified period of time in Linux. The cron jobs are used by cloud engineers to automate tasks that they want to be performed automatically on a regular basis, without having to run them manually every day or every hour.
