# Final Reflection: My Journey from Mission 1 to Mission 10

My journey from Mission 1 to Mission 10 was not always easy, but I learned a lot from every activity. When I first started, I was still unfamiliar with many things about Cloud Computing. Some terms and commands were new to me, and I sometimes had a hard time understanding what I needed to do. But as I continued with the missions, I slowly learned how things worked.

As I went through the activities, I learned how to use Linux commands, check server information, and understand the resources needed by a server. Of course, not all missions were easy for me. There were also times when I felt frustrated because some commands did not work or errors appeared while I was doing the activities. For the final mission, I worked with Ubuntu Server, Docker Compose, Nextcloud, and MariaDB. I also learned how to secure a server, create backups, and automate tasks using scripts and Cron Jobs.

Looking back, I realized how much I learned from these ten missions. There were many challenges, but each one helped me improve my skills and understand Cloud Computing better. I am proud that I was able to complete the activities even when some parts were difficult. I know I still have a lot to learn, but I am now more confident in using these tools.
