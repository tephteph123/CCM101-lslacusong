# Security Audit Report

## 1. The Principle of Least Privilege (PoLP)

The Principle of Least Privilege is that access to programs and data should be restricted to the necessary level for the jobs done by individual users. This will help keep cloud-based accounts secure and make sure that users don't be able to access essential files, or modify the server settings, without authorization.

## 2. Attack Surface
The attack surface is the sum total of points at which an attacker could attempt to access or attack a virtual machine. These can include open ports, services running, and weak passwords. Minimizing these points helps to prevent attacks on the server.

## 3. Default Deny Policy
If no firewall rule is configured to allow a particular connection, the Default Deny Policy prevents network traffic from passing through. This is safer as the attacker won't be able to connect via unapproved ports and services even if they are using unknown IP addresses.
