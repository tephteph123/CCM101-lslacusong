# Google Cloud Platform (GCP)

## Brief Overview

Google Cloud Platform (GCP) is a cloud computing platform that provides services for computing, storage, databases, networking, artificial intelligence, machine learning, and other cloud workloads.

## Global Infrastructure

Google Cloud operates a global cloud infrastructure that allows organizations to deploy applications and services in different geographic locations.

## Cloud Management Console

The Google Cloud Console is a web-based interface used to manage Google Cloud projects, services, resources, and configurations.

## Four Core Services

1. Compute Engine – provides virtual machine instances.
2. Cloud Storage – provides object storage.
3. Google Cloud VPC – provides networking.
4. Google Cloud IAM – manages identities and access.

## Three Advantages

1. Strong capabilities for Artificial Intelligence and Machine Learning.
2. Strong support for Kubernetes and containerized applications.
3. Global cloud infrastructure for applications and workloads.

## Typical Enterprise Use Cases

Google Cloud can be used for AI and machine learning, data analytics, web applications, containerized applications, databases, and enterprise workloads.
