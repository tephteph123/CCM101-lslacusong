# Client Recommendations

## Client A – Startup Company

### Recommended Platform: AWS

AWS is a suitable choice for the startup because it provides many cloud services that can support a growing mobile application. Its flexible cloud resources can help the company start with the resources it needs and scale as the application grows. AWS also provides services that can support application development, storage, and databases.

### Services

- Amazon EC2
- Amazon S3
- Amazon RDS

## Client B – University

### Recommended Platform: Microsoft Azure

Microsoft Azure is the most appropriate choice for the university because it already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft technologies and can support the university during its cloud migration. This can make it easier for the university to manage existing Microsoft-based services in the cloud.

### Services

- Azure Virtual Machines
- Microsoft Entra ID
- Azure Blob Storage

## Client C – AI Research Company

### Recommended Platform: Google Cloud Platform

Google Cloud Platform is a suitable choice for the AI research company because it provides strong Artificial Intelligence and Machine Learning capabilities. Google Cloud also provides infrastructure that can support high-performance computing workloads. These capabilities can help the company develop and run AI and ML applications.

### Services

- Compute Engine
- Google Cloud AI services
- Google Kubernetes Engine

## Client D – Global E-Commerce Company

### Recommended Platform: AWS

AWS is a suitable choice for the global e-commerce company because it provides global cloud infrastructure and scalable services. The company needs highly available infrastructure that can support customers around the world and handle changes in demand. AWS provides services that can support computing, storage, databases, networking, and scalable applications.

### Services

- Amazon EC2
- Amazon S3
- Amazon RDS
