# Amazon Web Services (AWS)

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform that provides a wide range of cloud services. AWS provides more than 200 fully featured services for computing, storage, databases, networking, security, analytics, and other business needs.

## Global Infrastructure

AWS operates a global cloud infrastructure through regions and Availability Zones. This global infrastructure allows organizations to deploy applications and services in different geographic locations.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services and resources.

## Four Core Services

1. Amazon EC2 – provides virtual computing resources.
2. Amazon S3 – provides object storage.
3. Amazon VPC – provides networking resources.
4. AWS IAM – manages identities and access to AWS resources.

## Three Advantages

1. Broad range of cloud services.
2. Global infrastructure for deploying applications and workloads.
3. Security and scalability for different business needs.

## Typical Enterprise Use Cases

AWS can be used for web applications, data storage, databases, enterprise applications, analytics, and other cloud workloads.
