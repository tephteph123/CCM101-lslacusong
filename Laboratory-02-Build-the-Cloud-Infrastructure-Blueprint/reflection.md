# Mission Reflection

This laboratory activity helped me understand the different components of cloud infrastructure and how they work together. Among the cloud infrastructure components, I think compute resources are the most important because they provide the processing power needed to run applications, execute commands, and perform workloads. Without sufficient compute resources, applications and services would not be able to function properly. However, I also realized that compute resources need storage, networking, and an operating system to provide a complete and usable cloud environment.

Linux also plays an important role in cloud computing because it provides a reliable environment and managing system resources. Using KillerCoda's Linux environment, I was able to learn some basic commands, check out system information and understand the cloud-based environment. I also found that technical documentation is important before deploying infrastructure because it will contain a clear record of the information about the system, its configurations, resources and procedures. Good documentation can reduce errors, facilitate trouble shooting, and enable other people to comprehend and operate the infrastructure.


During this laboratory activity, I learned new skills related to Linux, cloud infrastructure, GitHub, and Markdown documentation in this lab activity. I was instructed on how to use Linux commands, organize files, create documentation and how to use Git commands to commit and push my work to a GitHub repository. It's also been great for my GitHub portfolio, as I was able to structure my lab work, notes, screenshots and thoughts in a single repository. Overall, this mission helped me gain insight into cloud infrastructure, which will be useful for future Cloud Computing activities and projects, and to build my skills in using cloud computing resources.
