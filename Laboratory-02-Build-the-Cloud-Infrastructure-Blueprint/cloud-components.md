# Cloud Infrastructure Components

## Compute Resources

Compute resources are resources that are used to run commands, applications, and workloads, which are important in cloud computing because cloud services require processing power to operate. In the KillerCoda Linux environment, the virtual CPU is used to run Linux commands and perform laboratory activities.

## Storage Resources

Storage resources are used to store operating system files, applications, documents, files created during laboratory activities, etc., which are important in cloud computing because users and applications require reliable storage for their data. In the KillerCoda Linux environment, the available disk space is used to store the Ubuntu system files and the files generated during the activities of the laboratories.

## Networking Resources

Networking enables computers, servers, and applications to communicate and share data, and is crucial for cloud computing because cloud resources must be able to communicate with other resources and services. In the KillerCoda Linux environment, networking enables the Linux terminal to communicate with the outside world, like GitHub.

## Operating System

In cloud computing, the operating system is essential as it controls the resources of the computer and creates an environment in which applications and commands can be executed; in the KillerCoda Linux environment, I use Ubuntu 24.04.4 LTS as my Linux platform to run workloads and perform the laboratory activities.
