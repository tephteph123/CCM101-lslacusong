## Linux Commands Used

- `cd ~` – moves to the user's home directory.
- `cd` – changes the current working directory.
- `pwd` – displays the current working directory.
- `ls` – lists files and directories in the current location.
- `mkdir` – creates a new directory.
- `touch` – creates new empty files.
- `nano` – opens a text editor for creating or editing files.
- `find` – searches for and displays files and directories.
- `cp` – copies a file from one location to another.
- `whoami` – displays the username of the currently logged-in user.
- `hostname` – displays the hostname of the Linux environment.
- `cat` – displays the contents of a file or command output.
- `grep` – searches for specific text or patterns in command output.
- `uname -r` – displays the Linux kernel version.
- `lscpu` – displays CPU and processor information.
- `free -h` – displays memory and swap usage in a human-readable format.
- `df -h` – displays disk space usage in a human-readable format.

## Git Commands Used

- `git config --global user.name "lslacusong"` – sets the global Git username.
- `git config --global user.email "stephanielacusong729@gmail.com"` – sets the global Git email address.
- `git clone` – copies a remote GitHub repository to the local Linux environment.
- `git status` – displays the current status of the Git repository and shows untracked or modified files.
- `git add` – stages files so they can be included in the next commit.
- `git commit` – saves staged changes to the local Git repository with a commit message.
- `git push` – uploads committed changes from the local repository to GitHub.
