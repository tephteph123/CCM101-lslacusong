There are different purposes of monitoring logs and metrics. Events, warnings and errors from containers are displayed on logs. Metrics display a numerical representation of data, like CPU usage, memory usage, and network traffic. Logs are useful to me when I want to understand a specific problem and metrics are useful to me when I want to see how the system is performing.

For large enterprise companies, they have hundreds of tools such as Prometheus that can gather metrics from thousands of containers. They use Grafana to create dashboard visualizations of their CPU usage, memory usage, and container performance.
