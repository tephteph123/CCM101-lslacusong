I saw a significant difference between Docker containers and Virtual Machines for this activity. Docker containers are very quick to be started, compared to a Virtual Machine where you have to install and start a full operating system. Docker also requires less resources, making easier to setup a web server.

I've learned what is the importance of port mapping when I'm using a web server. The -p option is used to map ports from my computer to the ports in the container. This allows me to access the web server from localhost:8080. If I didn't map the ports, I wouldn't be able to get to the server via my computer.

I also learned what happens when I use docker rm. Docker removes the container, including the data stored inside its writable layer. Any files I created inside the container disappear after removal. I need a Docker volume when I want to keep important data.

Containerization also gives developers and IT operations teams a more consistent way to work. Developers can test applications using the same container setup used for deployment. This helps reduce setup problems and makes teamwork easier.
